# PRISM — Data Model

**Version:** 2.0 (SCALE/REWIRE Architecture)
**Storage:** SQLite (server-side, `prism.db`)
**Owner:** M4 (Assessment + Voice + Integration) with input from all members

---

## 1. Documents

**Table:** `documents`

**Lifecycle:** Created at upload time. Immutable after creation.

```sql
CREATE TABLE documents (
  document_id    TEXT PRIMARY KEY,         -- "doc_a1b2c3d4"
  title          TEXT NOT NULL,            -- "The Industrial Revolution"
  source_type    TEXT NOT NULL,            -- "pdf" | "text"
  source_length  INTEGER NOT NULL,         -- character count of original
  raw_text       TEXT NOT NULL,            -- full extracted text
  extraction_method TEXT NOT NULL,         -- "pdfjs" | "tesseract" | "paste"
  created_at     TEXT NOT NULL             -- ISO 8601
);
```

---

## 2. Sections

**Table:** `sections`

**Lifecycle:** Created during LLM content structuring. Immutable after creation.

```sql
CREATE TABLE sections (
  section_id      TEXT PRIMARY KEY,        -- "sec_001"
  document_id     TEXT NOT NULL,           -- FK → documents
  title           TEXT NOT NULL,           -- "Historical Context"
  sequence_number INTEGER NOT NULL,        -- 1-based ordering
  created_at      TEXT NOT NULL,
  FOREIGN KEY (document_id) REFERENCES documents(document_id)
);
```

---

## 3. Concepts

**Table:** `concepts`

**Lifecycle:** Created during LLM content structuring. Each concept is the atomic unit of the content graph.

```sql
CREATE TABLE concepts (
  concept_id      TEXT PRIMARY KEY,        -- "con_001"
  section_id      TEXT NOT NULL,           -- FK → sections
  document_id     TEXT NOT NULL,           -- FK → documents (denormalized for fast lookup)
  original_text   TEXT NOT NULL,           -- raw unadapted text for this concept
  sequence_number INTEGER NOT NULL,        -- ordering within section
  created_at      TEXT NOT NULL,
  FOREIGN KEY (section_id) REFERENCES sections(section_id),
  FOREIGN KEY (document_id) REFERENCES documents(document_id)
);
```

---

## 4. Content Variants

**Table:** `content_variants`

**Lifecycle:** Pre-generated by LLM at upload time. Cached permanently. This is what REWIRE retrieves.

```sql
CREATE TABLE content_variants (
  variant_id        TEXT PRIMARY KEY,      -- "var_con001_lv2"
  concept_id        TEXT NOT NULL,         -- FK → concepts
  level             INTEGER NOT NULL,      -- 1 (light), 2 (moderate), 3 (maximum)
  simplified_text   TEXT NOT NULL,         -- adapted text at this level
  visual_description TEXT,                 -- text description of visual/diagram
  strategy          TEXT NOT NULL,         -- "vocabulary_replacement + sentence_shortening"
  created_at        TEXT NOT NULL,
  FOREIGN KEY (concept_id) REFERENCES concepts(concept_id),
  UNIQUE(concept_id, level)
);
```

---

## 5. Questions

**Table:** `questions`

**Lifecycle:** Pre-generated by LLM at upload time. Cached permanently.

```sql
CREATE TABLE questions (
  question_id      TEXT PRIMARY KEY,       -- "q_con001_a"
  concept_id       TEXT NOT NULL,          -- FK → concepts
  text             TEXT NOT NULL,          -- "What was the Industrial Revolution?"
  type             TEXT NOT NULL,          -- "multiple_choice" | "true_false"
  options          TEXT NOT NULL,          -- JSON array: [{"id":"opt_1","text":"..."},...]
  correct_option_id TEXT NOT NULL,         -- "opt_1"
  explanation      TEXT NOT NULL,          -- shown on incorrect answer
  source           TEXT NOT NULL,          -- "ai_generated" | "fallback"
  created_at       TEXT NOT NULL,
  FOREIGN KEY (concept_id) REFERENCES concepts(concept_id)
);
```

**Note:** `options` is stored as a JSON string. Parsed on read.

## 6. Learner Profiles

**Table:** `learner_profiles`

**Lifecycle:** Created on first session. Updated when learner edits preferences. Persists across sessions.

```sql
CREATE TABLE learner_profiles (
  profile_id       TEXT PRIMARY KEY,       -- "profile_abc123"
  profile_type     TEXT NOT NULL,          -- "dyslexia" | "low_vision" | "cognitive_load" | "custom"
  typography       TEXT NOT NULL,          -- JSON: { fontFamily, fontSize, lineHeight, letterSpacing, wordSpacing, textAlign }
  color_scheme     TEXT NOT NULL,          -- "cream-on-dark" | "high-contrast" | "dark" | "light"
  adaptation_settings TEXT NOT NULL,       -- JSON: { simplificationLevel, chunkSize, readAloudRate, readAloudPitch }
  voice_settings   TEXT NOT NULL,          -- JSON: { voiceEnabled, preferredVoice, autoRead }
  created_at       TEXT NOT NULL,
  last_modified_at TEXT NOT NULL
);
```

**JSON schemas:**

### typography
```json
{
  "fontFamily": "'OpenDyslexic', 'Arial', sans-serif",
  "fontSize": 18,
  "lineHeight": 1.6,
  "letterSpacing": 0.12,
  "wordSpacing": 0.1,
  "textAlign": "left"
}
```

### adaptation_settings
```json
{
  "simplificationLevel": 1,
  "chunkSize": 3,
  "readAloudRate": 0.9,
  "readAloudPitch": 1.0
}
```

### voice_settings
```json
{
  "voiceEnabled": true,
  "preferredVoice": null,
  "autoRead": false
}
```

## 7. Learning Sessions

**Table:** `learning_sessions`

**Lifecycle:** Created when learner starts reading a document. Updated throughout the session.

```sql
CREATE TABLE learning_sessions (
  session_id       TEXT PRIMARY KEY,       -- "session_12345"
  document_id      TEXT NOT NULL,          -- FK → documents
  profile_id       TEXT NOT NULL,          -- FK → learner_profiles
  current_concept_index INTEGER NOT NULL DEFAULT 0,
  started_at       TEXT NOT NULL,
  last_activity_at TEXT NOT NULL,
  completed        INTEGER NOT NULL DEFAULT 0,  -- 0 or 1
  FOREIGN KEY (document_id) REFERENCES documents(document_id),
  FOREIGN KEY (profile_id) REFERENCES learner_profiles(profile_id)
);
```

---

## 8. Learner Signals

**Table:** `learner_signals`

**Lifecycle:** One row per concept interaction. Created when learner finishes interacting with a concept.

```sql
CREATE TABLE learner_signals (
  signal_id        TEXT PRIMARY KEY,       -- "sig_session12345_con001"
  session_id       TEXT NOT NULL,          -- FK → learning_sessions
  concept_id       TEXT NOT NULL,          -- FK → concepts
  variant_level    INTEGER NOT NULL,       -- which variant was displayed
  dwell_time       INTEGER NOT NULL,       -- milliseconds spent reading
  reread_count     INTEGER NOT NULL DEFAULT 0,
  scroll_back      INTEGER NOT NULL DEFAULT 0,
  help_requests    INTEGER NOT NULL DEFAULT 0,
  question_accuracy REAL,                  -- 0.0–1.0 (null if no questions answered)
  answer_latency   INTEGER,               -- average ms per question (null if none)
  retry_count      INTEGER NOT NULL DEFAULT 0,
  voice_help_requests INTEGER NOT NULL DEFAULT 0,
  recorded_at      TEXT NOT NULL,
  FOREIGN KEY (session_id) REFERENCES learning_sessions(session_id),
  FOREIGN KEY (concept_id) REFERENCES concepts(concept_id)
);
```

## 9. Adaptation History

**Table:** `adaptation_history`

**Lifecycle:** One row per REWIRE event. Records what SCALE decided, what changed, and the outcome.

```sql
CREATE TABLE adaptation_history (
  adaptation_id    TEXT PRIMARY KEY,       -- "adapt_001"
  session_id       TEXT NOT NULL,          -- FK → learning_sessions
  concept_id       TEXT NOT NULL,          -- FK → concepts
  trigger_signal_id TEXT NOT NULL,         -- FK → learner_signals (what triggered this)
  struggle_score   REAL NOT NULL,          -- computed score that triggered adaptation
  threshold        REAL NOT NULL,          -- threshold that was exceeded
  reason           TEXT NOT NULL,          -- human-readable reason
  thresholds_met   TEXT NOT NULL,          -- JSON array of threshold descriptions
  previous_variant_level INTEGER NOT NULL, -- level before adaptation
  new_variant_level INTEGER NOT NULL,      -- level after adaptation
  strategy         TEXT NOT NULL,          -- adaptation strategy applied
  explanation      TEXT NOT NULL,          -- "Why I adapted" message shown to learner
  pre_accuracy     REAL,                   -- question accuracy BEFORE adaptation
  post_accuracy    REAL,                   -- question accuracy AFTER adaptation (null until measured)
  outcome_delta    REAL,                   -- post_accuracy - pre_accuracy (null until measured)
  learner_accepted INTEGER,               -- 1=accepted, 0=reverted, null=not yet decided
  adapted_at       TEXT NOT NULL,
  outcome_measured_at TEXT,                -- when post-accuracy was recorded
  FOREIGN KEY (session_id) REFERENCES learning_sessions(session_id),
  FOREIGN KEY (concept_id) REFERENCES concepts(concept_id),
  FOREIGN KEY (trigger_signal_id) REFERENCES learner_signals(signal_id)
);
```

## 10. Answers

**Table:** `answers`

**Lifecycle:** One row per answered question.

```sql
CREATE TABLE answers (
  answer_id        TEXT PRIMARY KEY,       -- "ans_session12345_q_con001_a"
  session_id       TEXT NOT NULL,          -- FK → learning_sessions
  question_id      TEXT NOT NULL,          -- FK → questions
  concept_id       TEXT NOT NULL,          -- FK → concepts
  selected_option_id TEXT NOT NULL,        -- which option was chosen
  is_correct       INTEGER NOT NULL,       -- 0 or 1
  answer_latency   INTEGER NOT NULL,       -- milliseconds to answer
  attempt_number   INTEGER NOT NULL DEFAULT 1, -- 1 for first try, 2 for retry, etc.
  input_method     TEXT NOT NULL DEFAULT 'click', -- "click" | "voice"
  answered_at      TEXT NOT NULL,
  FOREIGN KEY (session_id) REFERENCES learning_sessions(session_id),
  FOREIGN KEY (question_id) REFERENCES questions(question_id),
  FOREIGN KEY (concept_id) REFERENCES concepts(concept_id)
);
```

## 11. Progress

**Table:** `progress`

**Lifecycle:** Updated after each concept interaction. Aggregates session-level metrics.

```sql
CREATE TABLE progress (
  progress_id      TEXT PRIMARY KEY,       -- "prog_session12345"
  session_id       TEXT NOT NULL UNIQUE,   -- FK → learning_sessions
  concepts_completed INTEGER NOT NULL DEFAULT 0,
  concepts_total   INTEGER NOT NULL,
  total_time       INTEGER NOT NULL DEFAULT 0,  -- milliseconds
  questions_answered INTEGER NOT NULL DEFAULT 0,
  questions_correct INTEGER NOT NULL DEFAULT 0,
  overall_accuracy REAL NOT NULL DEFAULT 0.0,
  adaptations_triggered INTEGER NOT NULL DEFAULT 0,
  completion_percentage REAL NOT NULL DEFAULT 0.0,
  last_updated     TEXT NOT NULL,
  FOREIGN KEY (session_id) REFERENCES learning_sessions(session_id)
);
```

## 12. Outcome Metrics

**View:** `outcome_metrics` (computed from adaptation_history)

This is a SQL view, not a table. Provides aggregate outcome data for the demo.

```sql
CREATE VIEW outcome_metrics AS
SELECT
  ah.session_id,
  COUNT(*) as total_adaptations,
  AVG(ah.outcome_delta) as avg_outcome_improvement,
  SUM(CASE WHEN ah.outcome_delta > 0 THEN 1 ELSE 0 END) as positive_outcomes,
  SUM(CASE WHEN ah.outcome_delta <= 0 THEN 1 ELSE 0 END) as negative_outcomes,
  AVG(ah.pre_accuracy) as avg_pre_accuracy,
  AVG(ah.post_accuracy) as avg_post_accuracy,
  SUM(CASE WHEN ah.learner_accepted = 1 THEN 1 ELSE 0 END) as accepted_count,
  SUM(CASE WHEN ah.learner_accepted = 0 THEN 1 ELSE 0 END) as reverted_count
FROM adaptation_history ah
WHERE ah.post_accuracy IS NOT NULL
GROUP BY ah.session_id;
```

## Entity Relationship Diagram

```
documents
  └── sections (1:N)
        └── concepts (1:N)
              ├── content_variants (1:N, by level)
              ├── questions (1:N)
              ├── learner_signals (1:N, per session)
              ├── adaptation_history (1:N, per session)
              └── answers (1:N, per session)

learner_profiles
  └── learning_sessions (1:N)
        ├── learner_signals (1:N)
        ├── adaptation_history (1:N)
        ├── answers (1:N)
        └── progress (1:1)
```

## Data Flow Across Architecture

| Architecture Stage | Reads | Writes |
|-------------------|-------|--------|
| Input (Upload) | — | `documents` |
| Content Structuring | `documents` | `sections`, `concepts`, `content_variants`, `questions` |
| Learner Profile | `learner_profiles` | `learner_profiles` |
| Initial Render | `concepts`, `content_variants`, `learner_profiles` | `learning_sessions`, `progress` |
| Signal Capture | — | `learner_signals` |
| SCALE Evaluate | `learner_signals`, `adaptation_history` | — (computation only) |
| REWIRE | `content_variants`, `questions` | `adaptation_history` |
| Assessment | `questions` | `answers` |
| Outcome Measurement | `adaptation_history`, `answers` | `adaptation_history` (update outcome fields) |
| Progress Update | `learner_signals`, `answers` | `progress` |

## MVP Constraints

**What is NOT in this schema (future work):**
- User authentication (no login/passwords)
- Multi-device sync (single server, single SQLite file)
- Long-term learner modeling across documents
- Shared sessions or collaboration
- Full audit trail beyond adaptation_history
- Cloud database (SQLite is embedded)
